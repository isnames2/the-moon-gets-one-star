A one-star review of the Moon, written for the make.fun bounty
[The Moon Gets One Star](https://make.fun/bounty/u-eager-stork-81-9647-the-moon-gets-one-star-768236e5).

`main.py` (pure Python standard library) writes the review to
`$MAKEFUN_OUTPUT_DIR/entry.txt`:

> One star. Ordered a full moon, got a sliver. No refund, no tracking number, and it still shows up late every month.

The entry is 115 characters, within the competition's 1–120 character gate,
and byte-identical on repeat runs.
